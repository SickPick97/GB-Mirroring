# Portable Windows runtime / Runtime Windows portatile

## English

Python 3.13.3 embedded and USB libraries were supplied with the contributor's package. Executables are unchanged; Python library sources are included. No game data or Python caches are distributed. Python notices: python/LICENSE.txt; additional dependencies: root THIRD_PARTY.md and licenses/.

python313._pth preserves isolation. Launchers add tools and vendor/celio_transport explicitly; no global Python installation is needed. Integrity hashes are in manifest.json. mGBA and native-renderer notices, source links and hashes are in their directories. From the project root run runtime/python/python.exe tools/check_portable.py for an offline check without USB communication.

## Italiano

Python embedded 3.13.3 e librerie USB provengono dal pacchetto ricevuto. Eseguibili invariati, sorgenti delle librerie Python inclusi. Nessun dato di gioco o cache. Avvisi Python in python/LICENSE.txt; altre dipendenze nel THIRD_PARTY.md e licenses/ alla radice.

Il runtime resta isolato; i launcher aggiungono i percorsi necessari. Nessuna installazione Python globale. Hash, licenze e sorgenti di riferimento sono inclusi. Il controllo indicato sopra è offline e non comunica con dispositivi USB.
