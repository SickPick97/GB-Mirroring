# mGBA graphics engine

Unmodified libretro core, version 0.11-219-e31759b, pinned by SHA256 in manifest.json. Copyright mGBA contributors, MPL-2.0 (LICENSE). Corresponding source: https://github.com/libretro/mgba/tree/e31759b . Build provenance: official Libretro Windows x86_64 nightly archive, URL in manifest; future archive contents may change, so the bundled hash is authoritative for this package.

The PC receiver loads only the project's own homebrew as an idle display host, and supplies video state exported by the GBA. No Pokemon ROM or save is bundled or required on the receiver. This is a prototype graphics renderer, not the final autonomous RP2040 renderer.
